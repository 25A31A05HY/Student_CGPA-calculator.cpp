# Student_CGPA-calculator.cpp


A simple C++ program to calculate CGPA based on course grades and credit hours.

## Features
- Takes grades and credits as input
- Calculates total grade points
- Computes CGPA
- Displays the final result

## Requirements
- C++ Compiler (GCC, G++, Visual Studio, CodeBlocks, etc.)

## How to Run

Compile the program:

```bash
g++ cgpa_calculator.cpp -o cgpa_calculator
